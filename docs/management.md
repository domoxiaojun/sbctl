# 用户、节点与协议管理

从 0.10.0 起，主控和受管节点程序都需要升级，才能使用协议配置和重启任务。当前主控为 0.10.3、节点工具为兼容的 0.10.1；已修复路由单字符串引用导致停用/删除误拒绝，以及归档网址刷新后筛选与批量恢复判断的问题。统计采样频率不变，不增加实时速率或连接流推送。

## 用户与授权

列表直接提供编辑资料、调整授权、禁用/重新启用、订阅管理和管理详情。资料编辑只改名称与备注，保留永久身份、凭据、授权版本和历史流量。

订阅管理可获取并复制 Surge/Mihomo 链接，也可重置链接。重置先吊销旧链接，再发布新链接；需要将新链接重新交付给用户。已经下载的代理配置仍然有效，重置链接不属于代理凭据轮换，也不会重启节点。

归档仅用于收起已经停用的记录，保留用户、操作记录和流量。服务端要求用户禁用、订阅已吊销、凭据已撤销且全部节点任务完成；失联节点尚未完成撤销时不能归档。支持选择当前页的可归档用户，整批校验后一次保存，最多 50 位。归档筛选可切换未归档、已归档和全部；恢复后仍是禁用状态，需单独重新启用才能恢复访问。

0.10.3 增加“删除用户”：在已归档列表的单条操作、详情或选中后的批量操作中使用，输入“删除”确认。删除前再次检查版本、禁用/归档状态、订阅与凭据撤销及所有节点任务结果；任一用户不满足条件，整批不删除，最多 50 位。删除后不能恢复，用户主记录、组关联、已撤销凭据和订阅记录移除；历史操作、审计、独立流量账本和撤销指纹保留。底层历史 API 的用量显示“已删除用户”，仍可按原用户 ID 查询，用户详情不再可用。0.10.4 移除网页中的“sbctl 用户”统计分类及原用户详情统计跳转，已有历史数据不随分类移除而删除。删除用户本身不下发节点任务或重启代理。

## 节点与协议

节点详情集中提供资料编辑、连接与运行检查、绑定更新、受控重启、协议入口和最近 20 项管理任务。任务保存于服务端，刷新页面后仍可查看；失败后可重试原任务，避免重新提交造成重复执行。

先点击“读取协议配置”获取当前配置版本，再执行管理操作：

| 操作 | 行为 |
| --- | --- |
| 新增 | 从节点已有的 AnyTLS、TUIC、VMess、VLESS、Shadowsocks 或 direct 入口复制 TLS、传输与协议设置，指定新标签、独立端口和新的本地凭据。创建成功后请保存表单中的凭据，关闭后不再展示。 |
| 编辑 | 调整监听 IP 和端口；direct 还可调整转发目标。保留原凭据和其他协议设置。 |
| 停用/启用 | 将入口配置移出/恢复至运行配置，停用期间保留配置以便恢复。 |
| 删除 | 删除入口，保留历史用量与私有回退材料。删除过的标签不能重新使用，以免混淆历史统计。 |

当前采用独立端口校验，已有其它入口使用的端口不能重复分配。新增入口使用节点本地凭据；sbctl 用户的统一授权和订阅仍由绑定的 AnyTLS/TUIC 主入口提供。两个主入口可以编辑监听参数，变更后重新生成订阅；由于授权和运行探针依赖它们，不能停用或删除。路由等配置引用的入口也会拒绝停用/删除，需先处理关联规则。

配置通过 sing-box 预检后才写入并重建容器，现有连接会短暂中断。任务保留原配置、模板、绑定和守卫材料，启动/探针检查失败时自动恢复；若回退也失败，节点保持阻止启动状态并报告错误，需处理故障后重试原任务。进程中断时保留恢复计划，同一任务按运行周期继续确认，避免重复重启。配置已被其他操作改变时拒绝覆盖。

管理任务中的密码与 UUID 在主控加密存储，协议清单和任务回执不返回凭据。节点上的恢复材料需要原配置，按私有文件保存，勿作为公开诊断附件发送。

本轮不包含任意协议从零配置、任意 JSON 编辑、普通凭据轮换、节点删除/停止或跨节点恢复矩阵。现有完整流量查询统一位于“流量统计”。
