# sing-box 全入口与用户统计验收

日期：2026-11-15，Asia/Singapore。范围：ovhus 主控和 yxvmhk 节点，Go 0.5.0。用户明确选择只统计 sing-box 各协议入口与用户用量，不统计 VPS 网卡。

## 实现与数据口径

- yxvmhk 全部 19 个入口纳入持久累计：1 个 AnyTLS、1 个 TUIC、1 个 VMess、1 个 VLESS、5 个 Shadowsocks 和 10 个 direct 转发入口。
- 流量页默认“协议入口”，可切换“sbctl 用户”和“节点本地用户”；节点详情展示相同统计。
- 现有本地命名用户为 `domo` 和补充显示名的 VLESS 用户。共享密码与匿名连接仅计入入口，不虚构个人身份；同一节点同名用户合并。
- 系统探针计入入口、不计入用户。入口与用户是两个统计角度，不相加。direct 是本机转发类型，不能据此识别加密的内层协议或远端用户。
- 新增统计项首次采样建立基线，不回填之前的内存计数；已有受管用户累计、账本 ID、统计起点和历史缺口均保留。删除入口/用户后保留已记累计。
- 快照新字段可省略，旧快照校验和保持兼容。原账本通过增量表保存新系列，未清空数据。

临时测试客户端使用现有 VMess、Shadowsocks 凭据，分别经实际代理下载 2,097,152 字节，HTTP 均为 200。凭据只在节点临时目录使用，测试后客户端容器和临时配置已清理。采样增量见[真实传输回执](probe-deltas.json)：

VMess 测试窗口有少量背景流量，两个下载增量相对 HTTP 正文分别高约 0.47% 和 0.43%，不能视为隔离的全协议性能基准。入口/本地用户到主控 API 的非零累计已确认；未对每个远端转发目标逐一做业务测试。

首次持续采样暴露了 gRPC JSON 对零值省略 `value` 字段的情况，原解析将它视为无效计数，导致第一次新增用户验收因统计超时失败；该身份由清理流程禁用。已修复为“存在计数行但省略值 = 0”，同时保留“整行消失/正值下降”的异常保护。新增回归测试覆盖受管用户、本地用户、入口、单向流量及下降冻结。

修复后重新执行真实新增用户 → AnyTLS/TUIC 认证 → 流量同步 → 禁用 → 两订阅链接 404，全部通过。该测试用户采集到上传 1,708 字节、下载 7,427 字节，现已禁用，节点最终 revision 8。已有用户上传 1,708 字节、下载 7,404 字节仍保留。见[受管用户实机回执](../../../ops/controller/full-traffic-managed-acceptance-20261115.json)。

## 未包含的能力

本轮完成单节点全入口与用户累计统计，不等于原产品所有里程碑已完成。VPS 网卡统计不在需求内；日/月趋势、实时速率、全协议用户授权管理、多节点推广和完整故障恢复矩阵仍未纳入本轮交付。用户自行管理的 HTTPS 站点未修改。
