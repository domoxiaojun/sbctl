# 移除 sbctl 用户统计分类

日期：2026-11-16。目标主控：0.10.4，兼容现有 0.10.1 节点工具。

## 范围

按用户要求，流量统计页仅保留“协议入口”和“节点本地用户”。删除原“sbctl 用户”按钮、明细组件、排行分支、用户管理跳转，以及用户详情中的对应流量跳转。旧 `scope=managed&user=…` 网址显示默认协议入口，不请求已移除分类或应用旧用户筛选；节点、日期等仍有效的筛选保留。节点本地用户名筛选、日趋势、排行联动、刷新与分页保留。

本轮为页面分类调整，用户管理、授权、订阅、节点运行及底层统计 API/账本均保留。原历史用量不会随页面分类移除而删除，不进行代理配置写入、节点工具升级、采样频率变更或站点反代变更。

## 本地验证

- 14 项前端单元测试、TypeScript、OpenAPI 一致性、生产构建和演示代码排除通过；ESLint 无错误，保留 3 条既有组件提示。
- 12 项定向 Chromium 场景通过，覆盖 375/1440 页面只保留两个分类、旧分类网址回退及请求中没有隐藏用户筛选、有效日期/节点保留、本地用户排行与刷新，以及受影响的节点工作区和用户删除流程。
- 发行工作流纳入新增分类场景，actionlint 和差异空白检查通过。
