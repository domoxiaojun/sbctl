# 已归档用户删除验收

日期：2026-11-16。目标主控：0.10.3。节点工具兼容 0.10.1。本轮仅增加用户删除，不修改代理配置或站点反代。

## 行为与边界

已归档且禁用、订阅/凭据已撤销、所有节点任务结束的用户可单条或批量删除，每批最多 50 位。删除前校验用户资料版本和授权版本，要求在确认框输入“删除”；任何一项不满足，整批不删除。同一请求 key 支持响应丢失后的安全重试。

删除用户主记录、组关联、已撤销凭据、订阅及用户管理记录；保留独立流量账本、历史操作、审计和节点撤销指纹。历史操作断开用户详情链接，用量继续按原用户 ID 查询并显示“已删除用户”，不再提供管理跳转。删除不会向节点发送任务或重启代理。数据库历史页、旧备份和既有任务恢复材料不在本次擦除范围内，不将普通删除描述为所有副本的安全擦除。

API：`POST /api/v1/users/delete`，请求 `users:[{id,version,revision}]`，要求有效管理会话、CSRF 和 `Idempotency-Key`。
