# 流量刷新、筛选与日期查询验收

日期：2026-11-16，Asia/Singapore。版本：0.7.0。范围：yxvmhk 的 sing-box 流量显示与 ovhus 主控统计查询。

## 根因与修改

采集和同步正常，原节点详情首屏显示 sbctl 受管用户累计，而 VMess 是已有协议入口。前轮实查受管用户累计仅 36,472 字节，同一快照中 VMess 上传 397,745,587、下载 1,203,972,810 字节。详情缺少轮询与刷新入口，统计页也缺少协议/日期筛选。

首屏现改为全部协议入口累计；详情与统计页共用筛选、区间汇总和明细组件。支持节点、协议、关键词/端口、当前/历史记录、用量或名称排序，网址保留查询条件。两处每 15 秒轮询，手动刷新展示结果反馈。入口、sbctl 用户和本地命名用户分开查看。

主控在原流量库内增加每日增量记录，API 读取只读导出。首次采样建立基线，重复采样去重，保持整数精度和原累计。查询按 UTC+8，首尾日期包含，最长 366 天。缺失日期不按零统计，断档和不完整记录保留明确状态；正常跨日增量按结束采样归档，边界最多偏移 180 秒。

## 必要验证

- 前轮 `make check` 的 go vet 与全量竞争检测通过；11 项前端单元测试、OpenAPI 一致性和生产构建通过，生产包不包含演示数据。
- 本轮针对性 Go 竞争检测通过：日期增量、跨日边界、大整数、重复采样、断档、导出恢复、旧数据库首次建立日期基线和累计保留。
- 扩展真实 Go HTTP 流程：带日期和协议的响应通过 OpenAPI 校验，入口及受管用户返回正确增量；非法日期返回 422。
- 5 项 Chromium 检查通过：375px 深色、1440px 浅色的筛选/日期/刷新/重载/空结果，以及生产包三种统计范围、15 秒自动更新和无明细显示未知。
- TypeScript 通过，ESLint 0 错误，保留 3 条既有 UI 组件 Fast Refresh 提示。发行工作流 actionlint 与契约一致性检查通过。
