# F0 前端验证记录

日期：2026 年 11 月 14 日。范围：本地 React 原型、API 草案、生成类型、演示交互和生产包边界。

## 实现与修复

F0 提供总览、节点、用户、流量、操作、告警、设置和组件验收页面，使用 React 19、TypeScript 5.9.3、Vite 8、Tailwind 4、shadcn/ui Base UI 组件、TanStack Query／Router／Table、React Hook Form 和 Recharts。具体版本由 `web/package.json` 与 `web/pnpm-lock.yaml` 锁定。

本次续接修复演示传输对空请求体的 JSON 解析；将浏览器测试与日常预览端口分离，拒绝复用其他项目的服务；统一新增与禁用的待确认请求存储和恢复，响应丢失后沿用原 key 查询；注销及会话过期清理查询与 mutation 缓存；为短屏弹窗增加高度上限和内部滚动。告警测试改为检查实际告警卡片，避免误选隐藏的下拉选项；手机截图等待数据加载完成后捕获。

## 验证结果

| 检查 | 结果与证据 |
| --- | --- |
| 精确依赖与锁文件 | pnpm 12.18.0 的 `install --frozen-lockfile` 通过，无重新解析依赖 |
| OpenAPI 生成一致性 | `pnpm api:check` 通过；生成声明与草案一致 |
| 业务逻辑 | 5 项 Vitest 通过：BigInt 精度、完整集合排序分页、幂等冲突、刷新恢复、禁用保留累计与失联节点状态 |
| 静态检查 | `pnpm lint` 无错误；官方生成的 Button、Badge 各有一条 Fast Refresh 导出提示，不影响构建 |
| 类型与生产构建 | `pnpm build` 内的 `tsc --noEmit`、Vite 构建及演示内容排除检查通过 |
| 浏览器交互 | 15 项场景通过，包含桌面及 375px 手机的新增／交付／禁用流程，以及筛选、分页、深链接、后退、表单校验、告警确认、焦点恢复和注销；新增及禁用各自验证响应丢失后只查询原操作、不重复写入 |
| 生产断开 API | 生产预览没有后端时显示管理 API 未接入，未出现演示总览或演示模式 |
| 响应式与双主题 | 375、768、1440px 的总览通过；375px 的用户列表与移动导航通过；未发现横向页面溢出或页面运行异常 |
| 弹窗与缩放 | 812×375 手机横屏和 720×500 的 200% 桌面浏览器缩放等效 CSS 视口通过；未把 CSS `zoom` 当成原生浏览器缩放 |
| 主题文字对比度 | 两主题的主要文字、辅助文字、主按钮、警告和危险文字等 14 对语义色检查通过；最低 4.94:1，属于基础色校验，不等同完整可访问性认证 |

浏览器使用 Playwright Chromium。按变更范围定向复跑失败或受影响场景，不额外重复已通过且不受影响的检查。实际 Safari、系统浏览器缩放菜单、屏幕阅读器尚未验收。

## 后续边界

F0 使用模拟数据和测试 API 响应。真实会话 Cookie、服务端 CSRF 与权限校验、持久作业、受限 SSH helper、流量账本、真实撤销、订阅发布和服务器 Compose 部署尚未实现或验证；不能将这里的通过结果等同 AT33–AT38 的全链路验收。没有安装本机数据库、运行本机 Docker 或连接 VPS。

M0 仍需管理 VPS、两台试点节点、Tailnet、镜像仓库、域名／证书及真实客户端版本。D01（撤销候选预检失败时是否停止整个受管容器）仍待 M2 前明确；F0 没有替用户决定这项策略。
